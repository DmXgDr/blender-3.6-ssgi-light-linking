# 配置说明

## 默认配置目录

默认读取 `%APPDATA%\Blender Foundation\Blender\3.6\`：

- `config/userpref.blend`：偏好设置。
- `config/startup.blend`：启动文件。
- `scripts/addons`：用户插件。
- `datafiles`：用户资源。

本版本与普通 Blender 3.6 默认共用这个目录。保存偏好或启动文件会写入共享目录。使用 MMD 工程时，请安装并启用兼容 Blender 3.6 的 MMD Tools。

## 独立配置

退出程序，在 `blender.exe` 同级的 `3.6` 目录下创建空的 `config` 文件夹，再启动程序。Blender 会优先使用包内配置目录。

## 色彩配置

使用 Blender 3.6 官方色彩管理，可在渲染属性中选择 Standard、Filmic 等显示变换。

`Start-Blender.cmd` 为本次启动选择包内的官方 OCIO 配置。直接运行 `blender.exe` 时，Blender 会按原生规则读取色彩配置；已有的 `OCIO` 环境变量可覆盖默认配置。

# 灯光链接和阴影链接：中文使用说明

适用：R4 / Blender 3.6.2 / EEVEE Legacy。界面可能显示中英文混合名称。

## 两种功能

| 功能 | 控制什么 | 示例 |
|---|---|---|
| Light Linking / 灯光链接 | 哪些物体接收指定灯的直接光 | 补光只照角色、不照舞台 |
| Shadow Linking / 阴影链接 | 哪些物体为指定灯挡光投影 | 让头发不再向脸投下这盏灯的阴影 |

阴影链接应加入“头发等遮挡物”，不是“接收阴影的脸”。它不会隐藏物体。

## 打开面板和拖入对象

1. 引擎选择 EEVEE；选中灯光。
2. 打开**对象属性**（橙色方框），展开 Light Linking 或 Shadow Linking。不是灯泡的数据属性。
3. 新建或选择链接集合。将属性编辑器右上方的图钉固定到这盏灯。
4. 从大纲视图把对象或集合名称拖到链接列表中。可以多选拖入、调整列表顺序，也可撤销/重做。
5. 设置 Include（包含、勾选）或 Exclude（排除、取消勾选），在 Rendered 视口或 F12 渲染中检查。

请添加实际参与渲染的网格/体积，或包含它们的集合。只加入骨架不会自动代表全部角色网格。

## 包含、排除、解除关联

| 无冲突的基本规则 | 未列出的对象 |
|---|---|
| 没有链接集合或集合为空 | 使用默认行为 |
| 仅有 Exclude 条目 | 其余对象照常参与 |
| 存在 Include 条目 | 限定被包含者参与 |

取消勾选表示“排除”，不是暂停。列表减号只移除关联；集合栏的 X 解除当前灯的整套链接。复杂重叠集合不应靠列表顺序猜测最终效果。

也可以先选目标物体、最后选灯，F3 搜索 **Link Receivers to Emitter**；阴影使用 **Link Blockers to Emitter**。

## 一盏灯同步给多盏灯：Ctrl+L

1. 先调好源灯的接收者集合与阻挡者集合。
2. 选择需要同步的目标灯，最后选择源灯，让源灯成为活动对象。
3. 鼠标放到 3D 视图，按 Ctrl+L，按需选择：
   - **Link Light Linking Collections**：共享灯光链接集合。
   - **Link Shadow Linking Collections**：共享阴影链接集合。
   - **Link Light and Shadow Linking Collections**：同时共享两者。

这是关联同一集合，随后编辑集合会影响所有使用它的灯。灯本身的颜色、功率和灯光数据不会因此被合并。需要独立调整时换成另一套集合。源灯没有集合时，相应共享操作会清除目标灯的该通道关联。

## 体积雾

把承载体积材质的物体或 Volume 对象加入灯光链接。可分别控制重叠雾的直接受光；排除照明仍保留雾本身的吸收和自发光。

World 体积按默认接收者处理：只排除一些对象不会排除 World；存在 Include 列表时 World 不在其中。需要明确单独控制雾时，优先使用物体体积。

体积作为遮挡介质的独立阴影链接不在本次新增范围内，体积消光仍参与整体衰减。

## Screen Space Ray Tracing 与阴影通道

本版修复了 SSRT 开启时被排除对象仍残留该灯直接高光的路径，并在链接变化时刷新相关视口历史。剩余亮度也可能来自其他灯、环境、自发光或间接反射。SSRT 的屏幕外信息、采样和历史累积限制仍然存在。

视图层的 **Shadow** 渲染通道用于向合成器输出阴影图像，与 Shadow Linking 列表不是同一功能。完成渲染后可在图像编辑器或 Render Layers 节点查看。

## 常见问题

- **没有面板**：确认打开的是本包程序、EEVEE、灯光对象的对象属性。
- **拖放后面板切换**：先用图钉固定目标灯；拖到列表区域。
- **MMD 工程不正常**：请安装并启用兼容 Blender 3.6 的 MMD Tools。
- **颜色不同**：核对显示变换、Look、曝光和工程资产；此版本使用 Blender 3.6 官方色彩管理。
- **英文物体名称**：列表按实际名称显示，不随界面语言翻译。
- **复杂工程**：先单独测试一盏灯，再扩大范围；超限警告出现后减少独立链接组合。
